Introduction

The range widget displays an HTML <input type="range"> that reflects a given tiddler field numeric value. Adjusting the range slider sets the tiddler field to the value.

Content and Attributes

The content of the <$range> widget is ignored.

Using Actions

Range widget: Actions

The sliders store their values in the integer-value and fractional-value fields of Output. Enable "Show log" to inspect the actions fired when dragging starts, the value changes, and dragging stops. Each entry includes the event, actionValue, and actionValueHasChanged. Entries in the log tiddler are numbered so that events fired within the same millisecond do not overwrite each other. Use "Clear Log" to reset the log.

JSON data indexes

Bind a range widget to a JSON property

The index attribute stores the slider value in a JSON property. Move the slider to update volume, or use the button to update the property and watch the slider follow. The label property is preserved.
